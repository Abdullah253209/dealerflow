# Roadmap

These are proposed improvements, not implemented features or release commitments.

## First priorities

- Complete print/PDF, full keyboard/screen-reader, UI backup restoration and Firefox/Safari checks; repeat the completed browser checks before releases.
- Improve Bangla coverage for validation messages originating in the accounting core.
- Collect feedback from actual small distributors using anonymized examples.
- Add an optional read-only screenshot gallery made from the fictional demo.
- Add dealer CSV import with a validated preview and clear matching rules.

## Later, after accounting review

- Move records to IndexedDB for larger datasets and stronger transactional writes.
- Add dated fridge-count history instead of using current metadata for past reports.
- Add optional invoice-level collection allocation, returns and ageing reports.
- Explore encrypted backups and user-controlled cloud synchronization.
- Add a server-backed multi-user edition with authentication and access controls, separately scoped from the local-only edition.

## Maintainer workflows to evaluate

- Codex-assisted review, new regression cases and bilingual documentation updates.
- Release checklist automation and reproducible build artifacts.

OpenAI APIs and Codex automation are not integrated into the current application.
