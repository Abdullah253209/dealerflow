# DealerFlow — বিক্রি ও আদায়ের হিসাব

ছোট ব্যবসা ও ডিস্ট্রিবিউটরের জন্য বিনা খরচের বাংলা–ইংরেজি ওয়েব অ্যাপ। ডিলারের বিক্রি, আদায়, বাকি ও মাসিক টার্গেট এক জায়গায় রাখুন। অ্যাকাউন্ট বা API key লাগে না।

**[English README](README.md)** · **[GitHub-এ প্রকাশের গাইড](PUBLISH_GUIDE_BN.md)**

## কী কী করা যায়

- ডিলারের নাম, ফোন, এলাকা, শুরুর বাকি ও ফ্রিজের সংখ্যা রাখা।
- মাস অনুযায়ী বিক্রির টার্গেট দেওয়া।
- বিক্রি ও আদায় যোগ, সম্পাদনা ও মুছে ফেলা।
- প্রতিটি ডিলারের খতিয়ান এবং মাসের শেষে পাওনা দেখা।
- অতিরিক্ত আদায় হলে ডিলারের জমা বা credit দেখা।
- ছয় মাসের চার্ট, টার্গেট অর্জন ও ফ্রিজপ্রতি বিক্রি দেখা।
- Excel থেকে UTF-8 CSV এনে লেনদেন যোগ করা। ভুল থাকলে পুরো import বন্ধ থাকবে।
- CSV রিপোর্ট ও JSON ব্যাকআপ ডাউনলোড করা।
- ব্রাউজারের Print → Save as PDF দিয়ে মাসিক রিপোর্ট রাখা।
- মোবাইল ও ডেস্কটপের জন্য আলাদা মাপের বিন্যাস।

## নিজের কম্পিউটারে চালাবেন যেভাবে

1. Node.js 22 বা পরের সংস্করণ লাগবে। [অফিশিয়াল Node.js ওয়েবসাইট](https://nodejs.org/en/download) থেকে নিন।
2. ZIP ফাইলটি Extract করুন।
3. যে ফোল্ডারে `package.json` আছে, সেটিতে Terminal খুলুন।
4. নিচের কমান্ড লিখুন:

```sh
npm start
```

5. ব্রাউজারে **http://127.0.0.1:4173** খুলুন।

`npm install` করতে হবে না। Terminal চালু রাখুন। বন্ধ করতে Ctrl+C চাপুন। শুধু `index.html`-এ double-click করলে অ্যাপ ঠিকভাবে চলবে না।

## প্রথমবার ব্যবহার

1. **Explore demo / ডেমো দেখুন** চাপলে কাল্পনিক ডেটায় সব ফিচার দেখে নিতে পারবেন। ডেমোর পরিবর্তন রিলোডে মুছে যায়। নিজের হিসাব আলাদা থাকে।
2. **Use my workspace / নিজের হিসাব খুলুন** চাপুন।
3. প্রথম ডিলার যোগ করুন। শুরুর তারিখের শুরুতে আগের কত টাকা বাকি ছিল লিখুন। আগের বাকি না থাকলে ০ দিন।
4. নির্বাচিত মাসের টার্গেট দিন। প্রতি মাসে টার্গেট আলাদাভাবে দিতে হবে।
5. **New transaction / নতুন লেনদেন** থেকে sale বা collection বেছে নিন।
6. রিপোর্টের মাস বদলে সে মাসের বিক্রি, আদায় ও শেষের বাকি দেখুন। ভবিষ্যৎ তারিখের রেকর্ডও রাখা যায়; নির্বাচিত মাসে সেগুলো অন্তর্ভুক্ত হয়।
7. কাজ শেষে **ডেটা ও সেটিংস → ব্যাকআপ ডাউনলোড** থেকে JSON ফাইল রাখুন।

## হিসাবের নিয়ম

**শুরুর বাকি + এই মাসে নতুন শুরুর বাকি + বিক্রয় − আদায় = শেষের ব্যালেন্স।**

উদাহরণ: শুরুর বাকি ১০,০০০ টাকা, বিক্রি ২০,০০০ টাকা এবং আদায় ১৫,০০০ টাকা হলে শেষে পাওনা ১৫,০০০ টাকা।

কোনো ডিলারের পাওনার চেয়ে বেশি আদায় হলে ব্যালেন্স ঋণাত্মক হবে। এটি ডিলারের জমা। অন্য ডিলারের পাওনা থেকে তা গোপনে বাদ যায় না; মোট পাওনা ও জমা আলাদা দেখায়।

শুরুর তারিখ মাসের মাঝখানে হলে তার আগের মাসগুলোতে সেই বাকি দেখাবে না। এই মাসে নতুন শুরুর বাকি হিসেবে আলাদা দেখাবে।

টাকা পয়সা হিসেবে পূর্ণসংখ্যায় রাখা হয়। সর্বোচ্চ দুই ঘর দশমিক দিন; কমা দেবেন না। বাংলা অঙ্কেও টাকার পরিমাণ লিখতে পারবেন।

## Excel থেকে CSV আনা

1. আগে ডিলার যোগ করুন।
2. **ডেটা ও সেটিংস → টেমপ্লেট নিন** চাপুন।
3. Excel-এ ফাইল খুলে রেকর্ড বসান। হেডারগুলো একই রাখুন:

| হেডার | কী লিখবেন |
| --- | --- |
| dealer | অ্যাপে থাকা ডিলারের নাম |
| date | `2026-11-21`-এর মতো তারিখ |
| type | `sale` অথবা `collection` |
| amount | `12500.50`-এর মতো টাকা; কমা ছাড়া |
| reference | বিল বা রসিদের নম্বর; খালি রাখা যায় |
| note | মন্তব্য; খালি রাখা যায় |

4. **CSV UTF-8 (Comma delimited)** হিসেবে সেভ করুন। `.xlsx` সরাসরি নেওয়া হয় না।
5. CSV import করে preview দেখুন। ভুল থাকলে ঠিক করে আবার দিন।
6. **রেকর্ড যোগ করুন** চাপলে সংরক্ষণ হবে। হুবহু একই রেকর্ড আবার এলে তা বাদ যাবে। আলাদা লেনদেন হলে আলাদা reference দিন।

## ডেটা সম্পর্কে মনে রাখবেন

- হিসাব এই ব্রাউজারে এই ডিভাইসে থাকে; ফোন বা অন্য কম্পিউটারে নিজে থেকে sync হয় না।
- ব্রাউজারের ডেটা মুছলে হিসাব হারাতে পারে। নিয়মিত JSON ব্যাকআপ নিন।
- ব্যাকআপ এনক্রিপ্ট করা নয়। নিরাপদ জায়গায় রাখুন; প্রকাশ্য GitHub repo-তে নিজের হিসাবের ব্যাকআপ দেবেন না।
- রিস্টোর করলে বর্তমান হিসাব বদলে যাবে। আগে বর্তমানটির ব্যাকআপ নিন।
- একসঙ্গে একটি ট্যাবে সম্পাদনা করুন। অন্য ট্যাবে পরিবর্তন হলে পুরোনো ট্যাব রিলোড করতে হবে।
- সর্বোচ্চ ৫০০ ডিলার ও ১০,০০০ লেনদেন রাখা যায়। এটি পূর্ণাঙ্গ inventory, tax বা accounting software নয়।
- ফ্রিজপ্রতি বিক্রির হিসাব বর্তমান ফ্রিজের সংখ্যা দিয়ে হয়; আগের মাসের আলাদা fridge history রাখা হয় না।
- প্রথমবার ঠিকভাবে লোড ও cache হওয়ার পর সমর্থিত ব্রাউজারে অফলাইনে চলে।

হিসাব, ফাইল যাচাই ও ডেটা সংরক্ষণের ২১টি automated test পাস করেছে। পরে সরাসরি ব্রাউজার পরীক্ষায় Save-এর একটি সমস্যা ও ছোট স্ক্রিনের layout সমস্যা ধরা পড়ে; দুটিই ঠিক করা হয়েছে। ডিলার ও লেনদেন Save, রিপোর্ট, বাংলা ভাষা ও রেকর্ড বজায় থাকা, filter, pagination, CSV import/export, JSON backup download, ৩২০/৩৯০ pixel layout ও অফলাইন reload যাচাই হয়েছে। বিস্তারিত আছে [যাচাইয়ের নথিতে](docs/BROWSER_QA.md)।

Print/PDF, UI দিয়ে backup restore, পূর্ণ keyboard/screen-reader পরীক্ষা ও Firefox/Safari পরীক্ষা বাকি আছে। GitHub-এ প্রকাশের পর সেখানকার deployment ও Actions-এর ফল দেখতে হবে। [পরীক্ষার তালিকা](docs/MANUAL_TESTING.md)-তে কোনগুলো হয়েছে ও কোনগুলো বাকি আছে আলাদা দেওয়া আছে।
